# ☕ Fundamentals of Java Programming

Este repositório reúne exercícios, exemplos e práticas voltadas para o aprendizado dos principais fundamentos da linguagem **Java**. O objetivo é consolidar conceitos essenciais por meio da resolução de problemas e implementação de código.

## 📚 Conteúdos abordados

Os tópicos explorados neste repositório incluem:

### 🔹 Fundamentos
- Estruturas de controle (if, else, switch, loops)
- Vetores e matrizes
- Comportamento de memória
- Arrays e listas (básico)

### 🔹 Programação Orientada a Objetos (POO)
- Classes e objetos
- Construtores
- Sobrecarga de métodos
- Encapsulamento
- Enumerações e composição
- Herança e polimorfismo

### 🔹 Recursos avançados
- Tratamento de exceções
- Manipulação de arquivos
- Interfaces
- Generics
- Collections (Set e Map)

### 🔹 Programação funcional
- Expressões lambda
- Conceitos básicos de programação funcional em Java

### 🔹 Tópicos adicionais
- Outros recursos e práticas importantes da linguagem Java

## 🎯 Objetivo

Este repositório tem como finalidade servir como material de estudo e apoio para desenvolvedores iniciantes e intermediários que desejam fortalecer sua base em Java.

## 🚀 Como utilizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/fundamentals-of-java-programming.git
2. Navegue pelos diretórios e escolha os tópicos que deseja estudar.
3. Execute os exemplos em sua IDE de preferência (como IntelliJ IDEA, Eclipse ou VS Code).

- Java
